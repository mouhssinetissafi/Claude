AUTO-EDITOR PRO STUDIO — CLOUD WINDOWS BUILD

This source contains a GitHub Actions workflow that builds the Windows Setup.exe on a real Windows cloud runner.
It avoids local Python/Node/FFmpeg setup problems.

After these files are pushed to the repository's main branch:
1. Open the repository on GitHub.
2. Click Actions.
3. Open "Build Windows Studio Installer".
4. If it did not start automatically, click "Run workflow" and choose main.
5. Wait for the job to turn green.
6. Open the completed run.
7. Under Artifacts, download "Auto-Editor-PRO-Studio-Windows".
8. Unzip it and run Auto-Editor-PRO-Studio-Setup.exe.
