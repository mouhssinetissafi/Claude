# inbox/

Drop one folder per job here for `--footage-only` mode:

    inbox/
      my_job/
        clip01.mp4
        clip02.mov
        topic.txt              # optional
        clip01.license.json    # optional: {"source": "...", "author": "...", "license": "...", "url": "..."}
        credits.json           # optional job-level manifest keyed by file name (or "default")

Original files are never modified. See docs/FOOTAGE_ONLY.md.
